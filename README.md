# NuxtFlow 

A dashboard demo project, built with Nuxt 4, Tailwind 4, and Reka UI.

## Project overview

### Description

NuxtFlow consists of a demo dashboard web-application, created for portfolio and learning purposes. Its name (NuxtFlow) is a combination of the framework used: Nuxt, and the design reference adopted: Flowbite.

### Design Reference

This project implements a design from the following public Figma doucment, created and provided by Flowbite:

- [Flowbite Pro Figma v2.10.0 - Homepage](https://www.figma.com/design/BwJpLnMEFPsqLDaSgylB0V/flowbite-pro-figma-v2.10.0?node-id=2465-181397&p=f)

Note: Permission was kindly granted for using the design linked above, for the present use case. This project and its author is not affiliated with Flowbite by any means. 

### Scope

The current implementation focsus solely in the dark theme version of the Homepage (Overview) page.

Please note that some adaptations, simplifications and ommisisons were made to better suit the present project goals and related time contraints.


## Period

The project took around 5 months to be completed, starting in January, 2026, and lasting to May, 2026. 


## Tools and Technologies

### Stack

Below are some of the main open source libraries used for creating the project:

- Nuxt 4 (Vue), as the main project framework.
- TailwindCSS for convinient responsive styling.
- Reka UI, for accessible UI components.
- Unovis (D3.js), for charts rendering.
- Vitest and Testing Library, for testing components, composables and utility functions.
- Iconify, for importing and displayng icons.
- date-fns, for date manipulation.

### Artificial Intelligence (AI)

AI tools were used to optimize the development process, as well as for exploring the available AI tools and its capabilities. The IA providers, models and tools include:
- Coplit
- Codex
- Gemini
- ChatGPT
- Claude

Besided helping with decision making in general, IA assisted basically with the following tasks:

- Code review and suggestions
- Inline prediction and scoped code generation
- API mocking creation
- Test suite creation
- Debugging

## Getting started

### Setup

Install dependencies:

```bash
pnpm install
```

### Development

Start the development server at `http://localhost:3000`:

```bash
pnpm dev
```

### Testing

Run all tests:

```bash
pnpm vitest run
```

### Production

Build for production:

```bash
pnpm build
```

Preview production build:

```bash
pnpm preview
```
